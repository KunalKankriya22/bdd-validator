Include/Exclude

Any row with the "Exclude from Commit" option selected when the "Commit" button is pressed will remain in the Paperless Audit workflow. — These items are typically addressed using the "Audit" functionality on this page (see the right most column).

If a row has the "Exclude from Commit" option selected when the "Commit" button is pressed the effect depends on the Status of that row.

  • If the row has an "OK" status that item will be removed from the Paperless Audit workflow and the audit will be completed.
  • If the row has a "HOLD" status that item will be removed from the Paperless Audit workflow and will also receive an Audit Interdiction (which must be resolved elsewhere in the application).
