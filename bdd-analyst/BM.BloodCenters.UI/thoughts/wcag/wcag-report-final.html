Add Accessibility Assertions to Spec Files — WCAG-016

Write Jasmine tests covering: (1) aria-expanded attribute on filter button toggles correctly on open/close; (2) document.activeElement returns to filter button after overlay closes; (3) LiveAnnouncer.announce() is called with correct message and politeness on data load success, zero results, and error. Validate Initial Focus Target in Filter Panel (AT Testing)

The cdkFocusInitial attribute on the Plasma File Type mat-select directs FocusTrap.focusInitialElementWhenReady() to focus the first form field instead of the close button. Verify with VoiceOver/NVDA that the announced landing point makes sense — some screen reader users prefer a heading announcement on entry. If the close button is preferred, remove cdkFocusInitial and the behavior reverts to first-tabbable.

Spot-Check Datepicker Toggle Accessible Name

Removing aria-label="Log Date" from the date input (WCAG-009) was correct. However, the <mat-datepicker-toggle> button inside the same form field derives its accessible name from Angular Material's internal labeling — verify with a screen reader that it announces as "Date, Open calendar" (or similar) rather than just "Open calendar" or nothing. No code change expected, but worth confirming in VoiceOver.

Consider adding an ESLint/stylelint rule flagging mat-mdc-focus-indicator or mat-focus-indicator inside display:none declarations to prevent recurrence.

Framework-Specific Guidance

Angular Binding Pattern

Always use [attr.aria-label]="'text'" on Angular Material components — plain aria-label="text" may be discarded by the MDC rendering layer in Angular 18+.

CDK Overlay Accessibility

Pair every Overlay.create() with FocusTrapFactory.create(). Use cdkFocusInitial on the first meaningful element. Always return focus to the trigger on close.

Angular Material Focus Indicators

Never use display:none on .mat-mdc-focus-indicator. Use CSS custom properties (--mdc-*, --mat-*) to restyle without destroying keyboard accessibility.

Status Announcements

Use CDK LiveAnnouncer.announce(msg, politeness) rather than managing live region <div>s manually. Use 'polite' for success, 'assertive' for errors.
