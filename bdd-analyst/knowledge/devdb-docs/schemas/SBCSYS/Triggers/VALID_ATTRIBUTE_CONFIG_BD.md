# VALID_ATTRIBUTE_CONFIG_BD

**Schema**: [[schemas/SBCSYS/SBCSYS|SBCSYS]]

**Type**: BEFORE EACH ROW
**Event**: DELETE
**Status**: ENABLED

## Trigger Body

```plsql
begin
	insert into SBCSYS.VALID_ATTRIBUTE_CONFIG_AUDIT

		CHAPTER_ID,PRODUCT_TYPE,ATTRIB_CLASS,

		INSERT_DATE,INSERT_USER,PROGRAM_ID,FCN_NAME,
		AUDIT_KEY,AUDIT_INSERT_DATS, AUDIT_INSERT_USER

	)
	values
	(

		:OLD.CHAPTER_ID, :OLD.PRODUCT_TYPE, :OLD.ATTRIB_CLASS,
		:OLD.ATTRIB_CODE, :OLD.ATTRIB_MODIFIER, :OLD.EFF_DATE,
		:OLD.TERM_DATE,:OLD.MODIFIED_DATE,:OLD.LAST_MODIFIED_BY,
		:OLD.INSERT_DATE,:OLD.INSERT_USER,'DELETE',:OLD.FCN_NAME,
		:OLD.AUDIT_KEY , SYSDATE , lt_user_session.get_userid

	);
end;
```
