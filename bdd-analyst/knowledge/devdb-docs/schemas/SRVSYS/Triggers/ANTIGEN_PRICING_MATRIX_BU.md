# ANTIGEN_PRICING_MATRIX_BU

**Schema**: [[schemas/SRVSYS/SRVSYS|SRVSYS]]
**Table**: [[schemas/SRVSYS/Tables/ANTIGEN_PRICING_MATRIX|ANTIGEN_PRICING_MATRIX]]
**Type**: BEFORE EACH ROW
**Event**: UPDATE
**Status**: ENABLED

## Trigger Body

```plsql
begin
  insert into ANTIGEN_PRICING_MATRIX_AUDIT
    (
	ANTIGEN_QTY,
	STD_PRICE,
	EFF_DATE,
	LAST_MODIFIED_DATE,
	TERM_DATE,
	SERVICE_CODE,
	ANTIGEN_DESC,
	AUDIT_KEY,
	PROGRAM_ID,
	AUDIT_INSERT_USER,
	AUDIT_INSERT_DATE
	)
    values
	(
	:new.ANTIGEN_QTY,
	:new.STD_PRICE,
	:new.EFF_DATE,
	:new.LAST_MODIFIED_DATE,
	:new.TERM_DATE,
	:new.SERVICE_CODE,
	:new.ANTIGEN_DESC,
	:new.AUDIT_KEY,
	'UPDATE',LT_USER_SESSION.GET_USERID,
	sysdate
	)
  ;
end ;
```
