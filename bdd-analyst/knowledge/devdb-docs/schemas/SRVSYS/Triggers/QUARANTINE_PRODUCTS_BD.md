# QUARANTINE_PRODUCTS_BD

**Schema**: [[schemas/SRVSYS/SRVSYS|SRVSYS]]
**Table**: [[schemas/SRVSYS/Tables/QUARANTINE_PRODUCTS|QUARANTINE_PRODUCTS]]
**Type**: BEFORE EACH ROW
**Event**: DELETE
**Status**: ENABLED

## Trigger Body

```plsql
begin
  insert into QUARANTINE_PRODUCTS_AUDIT
  (	CHAPTER_ID,
	UNIT_ID,
	PRODUCT_CODE,
	ALIQUOT,
	INSERT_DATE,
	INSERT_USER_ID,
	QU_REASON,
	COLL_DATE,
	AUDIT_KEY,
	PROGRAM_ID,
	AUDIT_INSERT_USER,
	AUDIT_INSERT_DATE
  )
  values
  (	:old.CHAPTER_ID,
	:old.UNIT_ID,
	:old.PRODUCT_CODE,
	:old.ALIQUOT,
	:old.INSERT_DATE,
	:old.INSERT_USER_ID,
	:old.QU_REASON,
	:old.COLL_DATE,
	:old.AUDIT_KEY,
	'DELETE',LT_USER_SESSION.GET_USERID,
    sysdate
  ) ;
end ;
```
