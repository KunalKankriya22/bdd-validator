1) Signing JAR files Document.doc ---> describes the process of signing JAR files, please go through the whole document before applying the changes.

2) sign_webutil.sh ---> Contains LifeTrak specific settings. Provided by Oracle and modified for LifeTrak.

3) resign_jar.sh ---> Contains LifeTrak specific settings for resigning jar files. Not provided by Oracle. 

4) LTmanifest.txt ---> Manifest file used for signing of jar files.

5) Export_Certificate_cmds.txt ---> File contains the commands used for exporting certificate.

6) LifeTrak.csr ---> Sample certificate generated.
