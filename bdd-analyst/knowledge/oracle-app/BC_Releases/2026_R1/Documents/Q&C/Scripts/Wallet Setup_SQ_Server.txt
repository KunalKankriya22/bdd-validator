### SQA Server Wallet Setup Instructions

1> Create wallet directory in database server as oracle OS user

	mkdir -p /apps/product/19.0.0/admin/bcqas/wallet/tde

2> Load the DigiCert root certificate in above created wallet directory location

3> Change directory to wallet directory

	cd /apps/product/19.0.0/admin/bcqas/wallet/tde

4> Create wallet cert in the database using below commands 

. oraenv
{Enter the database name --> bcqas}



orapki wallet create -wallet /apps/product/19.0.0/admin/bcqas/wallet/tde -pwd Password1

orapki wallet create -wallet /apps/product/19.0.0/admin/bcqas/wallet/tde -auto_login

orapki wallet add -wallet /apps/product/19.0.0/admin/bcqas/wallet/tde -trusted_cert -cert "/apps/product/19.0.0/admin/bcqas/wallet/tde/DigiCertGlobalRootG2.crt" -pwd Password1


5> Update the sqlnet.ora file with below content --> /apps/product/19.0.0/dbhome_1/network/admin/sqlnet.ora 
 --> change the database name

WALLET_LOCATION =
   (SOURCE =
     (METHOD = FILE)
     (METHOD_DATA =
       (DIRECTORY = /apps/product/19.0.0/admin/bcqas/wallet/tde)
     )
   )


6> Grant db permissions to util & donsys users for wallet view

	Grant select on sys.V_$ENCRYPTION_WALLET to util,donsys;

7> Open the wallet using below SQL grants
	ADMINISTER KEY MANAGEMENT SET KEYSTORE OPEN IDENTIFIED BY Password1;

	ADMINISTER KEY MANAGEMENT CREATE AUTO_LOGIN FROM KEYSTORE '/apps/product/19.0.0/admin/bcqas/wallet/tde' IDENTIFIED BY "Password1";

8> Add the qc9.wellsky.com in Database server's /etc/hosts file with binded IP like below

	74.206.113.76	qc9.wellsky.com	qc9.wellsky.com


9> Create Network ACL for qc9.wellsky.com for UTIL & DBADMN users


BEGIN
DBMS_NETWORK_ACL_ADMIN.append_host_ace (
host       => 'qc9.wellsky.com',
lower_port => null,
upper_port => null,
ace        => xs$ace_type(privilege_list => xs$name_list('http', 'connect'),
principal_name => 'util',
principal_type => xs_acl.ptype_db));
END;
/

BEGIN
DBMS_NETWORK_ACL_ADMIN.append_host_ace (
host       => 'qc9.wellsky.com',
lower_port => null,
upper_port => null,
ace        => xs$ace_type(privilege_list => xs$name_list('http', 'connect'),
principal_name => 'dbadmn',
principal_type => xs_acl.ptype_db));
END;
/



10> Restart the database.
