Steps to Execute the Import Script at BBAK

1. Execute the "BBAK_Refine_ConvertProductsTable.sql" script to filter records from the CONVERT_PRODUCTS table and place them into the CONVERT_PRODUCTS_TEMP table. The script will also remove the duplicate records from the CONVERT_PRODUCTS_TEMP table and place the remaining records in the CONVERT_PRODUCTS_TEMP1 table. Login as ops$sbcsys/sbcsys to run the script.

2. Ecexute the "BBAK_LabDeleteStmts.sql" script to delete the records from the below Lab tables. Login as ops$sbcsys/sbcsys to run the script.
Warning: Make sure that if any records need to be kept, then they need to be backed up.

3. Ecexute the "BBAK_DistDeleteStmts.sql" script to delete the records from the below Distribution tables. Login as ops$srvsys/srvsys to run the script.
Warning: Make sure that if any records need to be kept, then they need to be backed up.

4. Execute the "BBAK_DisableTriggers.sql" script to disable the "Before Insert" triggers on the tables where the records are being inserted. Login as ops$sbcsys/sbcsys to run the script.

5. Execute the "BBAK_ImportScript.sql" Script to import data into BBAK. Login as ops$sbcsys/sbcsys to run the script.

6. Execute the "BBAK_CheckErrors.sql" script to check for any errors that might have occurred when the script was run. Login as ops$sbcsys/sbcsys to run the script.

7. Execute the "BBAK_ImportFromALAB.sql" script to import the records from the ALAB database. Login as ops$sbcsys/sbcsys to run the script.

8. Execute the "BBAK_CheckErrorsForALAB.sql" script to check for any errors that might have occurred when the script was run. Login as ops$sbcsys/sbcsys to run the script.

9. Execute the "BBAK_EnableTriggers.sql" script to enable the "Before Insert" triggers on the tables where the records were inserted. Login as ops$sbcsys/sbcsys to run the script.
