Unable to connect errors:
  a. Login to the db server.
  b. Ping the LDAP server.
  c. Install ldapsearch:
     - Login as oracle (alternatively login as wsadmin)
     - Switch to wsadmin user: su wsadmin
     - Enter password for wsadmin
     - Switch to root user: sudo su -
     - Enter password for wsadmin
     - Run ldapsearch command: ldapsearch
     - If "Command not found" error occurs, install package 'openldap-clients'
     - Exit from root user: exit
     - Exit from wsadmin user: exit
  d. Run few ldapsearch commands to see if able to connect to AD server and retrieve the details for service account:
     - Replace <scheme> with the desired scheme (e.g., ldap)
     - Replace <hostname> with the LDAP server hostname
     - Replace <portnumber> with the LDAP server port number
     - <scheme>://<hostname>[:portnumber]
     - Run the following ldapsearch command:
       ldapsearch -x -D "CN=Wellsky LDAP,OU=Service and Vendor Accounts,OU=Users,OU=BBAK Anchorage,DC=BBAK,DC=ORG" -w 'password' \
                  -H ldap://bbak-dc3.bbak.org -b "OU=Users,OU=BBAK Anchorage,DC=BBAK,DC=ORG" \
                  -s sub -x "cn=Wellsky LDAP"
     - Run the following ldapsearch command with a specific port number:
       ldapsearch -x -D "CN=Wellsky LDAP,OU=Service and Vendor Accounts,OU=Users,OU=BBAK Anchorage,DC=BBAK,DC=ORG" -w 'password' \
                  -H ldap://bbak-dc3.bbak.org:389 -b "OU=Users,OU=BBAK Anchorage,DC=BBAK,DC=ORG" \
                  -s sub -x "cn=Wellsky LDAP"
     - Run the following ldapsearch command using -h and -p options:
       ldapsearch -x -D "CN=Wellsky LDAP,OU=Service and Vendor Accounts,OU=Users,OU=BBAK Anchorage,DC=BBAK,DC=ORG" -w 'password' \
                  -h bbak-dc3.bbak.org -p 389 -b "OU=Users,OU=BBAK Anchorage,DC=BBAK,DC=ORG" \
                  -s sub -x "cn=Wellsky LDAP"
